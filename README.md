Deepfake Detection System

Overview
MaskOff is an advanced deepfake detection system designed to identify fake images using AI/ML models trained in-house. This project aims to deliver a robust SaaS solution for deepfake detection, ensuring high accuracy and a seamless user experience.

Features
Deepfake Image Detection
Powered by a ResNet50-based model.
Provides a web interface for displaying detected deepfakes.
Integration with a Flask-based frontend for enhanced user experience.
Real-time and accurate deepfake identification.
Web Application Features
Navigation bar for seamless navigation.
Pricing plans for SaaS-based implementation.
Drag-and-drop file upload for user convenience.

Frontend
Tailwind CSS
Flask
REST API for communication

Backend
FastAPI (for future scalability)
Machine Learning
TensorFlow / PyTorch
ResNet50 for image classification
